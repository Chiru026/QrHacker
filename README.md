# 🚀 QrHacker

A modern, responsive QR Code Scanner & Generator built using **HTML**, **CSS**, and **JavaScript**.

QrHacker provides a clean cyber-inspired interface for scanning and generating QR codes quickly on both desktop and mobile devices.


# ✨ Features

## 📷 QR Scanner

- Camera QR Scanner
- Image Upload Scanner
- Instant QR Detection
- Copy Scan Result
- Open Website Links
- Scan Again

---

## ⚡ QR Generator

- URL → QR Code
- Text → QR Code
- Instant QR Generation
- Download as PNG
- Download as JPG
- Generate Again

---

## 📱 Responsive Design

- Desktop Friendly
- Tablet Friendly
- Mobile Friendly
- Responsive Navigation
- Smooth Animations

---
